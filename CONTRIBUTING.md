# Contributing to Paint-WebApp 🎨

This Paint-WebApp is the OG version of digital creativity. If you want to contribute to this invention, read the instructions below carefully.

---

## How to Contribute

### 1. Reporting Bugs
- Check if the bug is already in the Issues tab.
- If not, open a new issue. Explain what happened, what you expected, and provide a screenshot.

### 2. Feature Requests
- Want to add new brushes, layers, or filters? Open an issue with the "enhancement" tag.

### 3. Pull Requests 
1. Fork this repo.
2. Create a branch: git checkout `-b feature/NewPaintingTool`
3. Commit your changes: `git commit -m 'Added a cool neon brush'`
4. Push it: `git push origin feature/NewPaintingTool`
5. Open a Pull Request.
